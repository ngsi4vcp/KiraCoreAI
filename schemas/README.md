# Машиночитаемые контракты

## Назначение

Каталог schemas/ фиксирует техническую форму основных слоёв Кира:Ядра.

Схемы являются контрактами между исполняемыми компонентами. Они не заменяют G22 и не имеют права изменять конституционный смысл проекта.

## Файлы

- core.schema.json — верхнеуровневый состав ядра;
- state.schema.json — сохраняемое состояние сессии;
- memory-record.schema.json — единичная запись памяти.

## Правило

Ключи JSON и перечисления являются техническими идентификаторами и могут оставаться на английском языке для стабильности машинного интерфейса.

Все title, description и поясняющая документация схемы должны быть на русском.

## Связь с геномом

Схема не является вторым геномом.

При расхождении между реализацией схемы и конституционными правилами приоритет имеет активный канонический текст GENOME/genome.txt соответствующей ревизии. Архитектурный конфликт оформляется как отдельное предложение изменения, а не исправляется молча в коде.
