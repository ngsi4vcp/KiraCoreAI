# Машиночитаемые контракты

Каталог schemas/ фиксирует техническую форму основных слоёв Кира:Ядра.

## Файлы

- core.schema.json — состав основных слоёв;
- core-state.schema.json — агрегированный снимок текущего runtime-состояния;
- state.schema.json — состояние сессии;
- memory-record.schema.json — единичная запись памяти;
- conversation-message.schema.json — единичное сообщение разговора;
- model-request.schema.json — нормализованный запрос к модели;
- model-response.schema.json — нормализованный ответ модели;
- genome.schema.json — машиночитаемое представление активного генома.

Схемы фиксируют технический контракт. Они не заменяют текст GENOME/genome.txt и не получают права изменять его смысл.

При расхождении архитектурный конфликт оформляется как отдельное предложение изменения, а не исправляется молча в коде.
