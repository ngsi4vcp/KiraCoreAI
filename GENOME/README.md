# GENOME

GENOME — активная точка загрузки текущего генома для runtime.

## Файлы

- genome.txt — активный текст генома;
- G22.txt в корне проекта — шаблон и база ревизии 22, runtime его не читает.

## Инвариант источника

GENOME/genome.txt является каноническим текстом активной ревизии.

Парсер строит из него:
- список разделов;
- индексы по ID;
- индексы по частям;
- индексы по runtime-целям.

Эти структуры производны. Они не являются вторым источником истины и не редактируются как отдельный геном.

## Runtime-цели

Каждый раздел несёт TARGETS. Примеры: identity, session, protocol, memory, history, state, environment, context.

Это позволяет будущему harness распределять секции по архитектурным контурам без эвристического поиска по заголовкам.
