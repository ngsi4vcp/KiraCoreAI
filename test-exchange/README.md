# Обмен тестовыми файлами

Папка для файлов, которыми обмениваемся во время Android-тестирования KiraCoreAI.

Рекомендуемые подпапки/имена:
- apk/ — актуальный тестовый APK; имя содержит номер CI-прогона; предыдущие версии доступны через историю Git;
- device-evidence/ — ZIP с результатами A0.D1;
- screenshots/ — скриншоты;
- logs/ — текстовые логи;
- notes/ — дополнительные заметки.

Не загружать сюда пароли, API-ключи, приватные ключи, содержимое SecureStore или иные секреты.

Текущая Android-база: branch `android/alpha-parity`.
