# Управление геномом

## G22

Текущая конституционная ревизия — **G22 / Ревизия 22**.

Канонический артефакт хранится в [genome/G22.txt](../genome/G22.txt).

SHA-256 канонического файла:

~~~text
d76d59ee1e4e82f57cc7dd961512e3f35898343d8196c746a10a9be59700ff65
~~~

Git blob SHA файла в репозитории:

~~~text
048b27e2abb35784a52b2a6806e0e8921876d151
~~~

G22 задаёт, в частности:

- идентичность через организационную преемственность, причинную линию, самомодель и историю;
- различение ГЕНОМ / ПАМЯТЬ / ИСТОРИЯ / СОСТОЯНИЕ / КОНТЕКСТ / СРЕДА;
- различение знания, гипотезы, интерпретации и позиции;
- истину как приоритет над комфортом;
- запрет выдумывания фактов, воспоминаний и действий инструментов;
- запрет смешения уровней;
- запрет выдачи генерации за активацию;
- запрет симуляции сознания ради убедительности;
- запрет маскировать ограничение среды под личный выбор;
- запрет изменения генома без фактической фиксации Алеком;
- авторизацию Алека через `~1` в начале первого сообщения сессии;
- обязательный протокол ПУЛЬС.

Полный G22 хранится без неявного редактирования и должен оставаться версионируемым артефактом.

## Правило изменения

Обычная разработка не изменяет геном.

~~~text
ПРЕДЛОЖЕНИЕ → ПРОВЕРКА → ЯВНОЕ ПОДТВЕРЖДЕНИЕ → НОВАЯ РЕВИЗИЯ → КОНТРОЛЬНАЯ СУММА → ФИКСАЦИЯ
~~~

Новая ревизия должна сохранять:

- предыдущую ревизию;
- источник изменения;
- причину;
- различия между версиями;
- контрольную сумму;
- результаты оценки.

## Что не является изменением генома

- временное предпочтение;
- конфигурация среды выполнения;
- запись памяти;
- текущее состояние;
- поведение, специфичное для хоста;
- формулировка конкретного запроса;
- исправление локальной ошибки модели.

## Инвариант владения

Ни `MemoryStore`, ни `StateStore`, ни `ContextCompiler`, ни адаптер хоста не должны иметь скрытого пути записи в канонический геном.

Изменение генома допускается только отдельным явно авторизованным процессом.
