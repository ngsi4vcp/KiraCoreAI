# Управление геномом

## Источник истины

Каноническим активным источником является GENOME/genome.txt.

G22.txt в корне — шаблон и база текущей разработки. Он не загружается runtime.

## Жизненный цикл изменения

Кандидат → анализ → предложение → явное утверждение Алека → новая ревизия.

Изменение текста GENOME должно быть осмысленным изменением конституционного документа, а не обновлением производного индекса.

## Производные структуры

После загрузки создаются:
- секции;
- индексы по ID;
- индексы по runtime-целям;
- представление GenomeStore;
- оперативные выборки для ContextCompiler.

Ни одна из этих структур не может обратно изменять исходный текст генома.

## Проверяемые свойства

- стабильные ID;
- отсутствие дубликатов;
- наличие обязательных секций;
- соответствие KIRA-GENOME;
- ревизия;
- SHA-256 загруженного текста;
- отделение root G22.txt от runtime-пути.


## Защита привилегированного authority plane

Изменение способа хранения/упаковки защищённых частей генома не является обычным runtime-параметром.

Если для sealed packaging потребуется изменение канонического формата GENOME или состава его разделов, это оформляется как отдельная кандидат-ревизия и проходит утверждение Алека.

Производные security projection, encrypted payload и runtime capability grants не становятся новым источником истины вместо GENOME.
