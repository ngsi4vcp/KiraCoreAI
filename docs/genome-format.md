# Формат KIRA-GENOME

## Назначение

KIRA-GENOME — текстовый машиночитаемый формат активного генома Кира:Ядра.

Цель формата — разделить человеческую редактируемость и строгую загрузку runtime.

## Структура документа

Документ начинается с @@GENOME и заканчивается @@ENDGENOME.

Заголовок содержит:
- FORMAT;
- FORMAT_VERSION;
- REVISION;
- SERIES;
- LANGUAGE;
- DOCUMENT_KIND;
- GOVERNANCE.

Каждый логический блок задаётся маркером @@SECTION ID.

После него следуют метаданные:
- TYPE — семантический тип;
- PART — номер части;
- TARGETS — runtime-контуры;
- MUTABILITY — immutable или stateful;
- TITLE — человекочитаемое название.

Маркер @@BODY начинает исходное содержание блока. Маркер @@END закрывает блок.

## Правила редактора

ID раздела стабилен и используется кодом. TITLE можно уточнять без изменения ID.

Содержимое BODY не интерпретируется по догадке. Runtime получает его как фактический текст.

Дублирование ID, пропуск обязательного поля, незакрытая секция или неизвестный формат должны останавливать загрузку.

## Разделение ролей

Корневой G22.txt — шаблон разработки.

GENOME/genome.txt — активный источник рантайма.

Database, store и index — производные представления.

Нельзя считать два разных файла одновременно каноническим геномом.
