# Архитектурные решения

## ADR-0001 — Кира:Ядро отделено от хоста

**Статус:** принято

Кира:Ядро не является конкретной моделью или средой выполнения.

## ADR-0002 — GitHub является источником истины проекта

**Статус:** принято

Нормативные архитектурные решения, спецификации, схемы и версии живут в репозитории.

## ADR-0003 — Геном, состояние, память, история и контекст разделены

**Статус:** принято

Каждый слой имеет отдельную семантику и права изменения.

## ADR-0004 — Изменение генома является отдельной транзакцией

**Статус:** принято

Память, состояние и контекст не могут непосредственно изменять геном.

## ADR-0005 — Первый эксперимент строится вокруг минимальной среды Кира

**Статус:** принято

Конкретные hosts рассматриваются как заменяемые среды.

## ADR-0006 — Сначала семантика, затем масштабирование

**Статус:** принято

Сначала доказываются основные контракты ядра.

## ADR-0007 — Модель не равна когнитивной архитектуре

**Статус:** принято

Модель — вычислительный компонент; runtime управляет состоянием, контекстом, валидацией и сохранением.

## ADR-0008 — Русский язык является каноническим

**Статус:** принято

Русский — основной язык нетехнической документации и канонической части GENOME.

## ADR-0009 — Сначала минимальный исполняемый контракт

**Статус:** принято

Первым исполняемым артефактом является Kira-native runtime, а не конкретный агентный framework.

## ADR-0010 — Разговор хранится отдельно от памяти

**Статус:** принято

Полная переписка может быть существенно больше структурированной памяти и должна иметь отдельный append-oriented store.

## ADR-0011 — ModelAdapter скрывает поставщика API

**Статус:** принято

OpenRouter, Google Gemini и LM Studio используют общий нормализованный контракт ModelRequest/ModelResponse.

## ADR-0012 — ПУЛЬС принадлежит runtime

**Статус:** принято

Модель не обязана воспроизводить ПУЛЬС. Runtime формирует его после успешного ответа и сохраняет как PulseStamp.

PulseStamp является корреляционной меткой, а не primary key.

## ADR-0013 — Память активируется отдельно

**Статус:** принято

Model output не может напрямую создать approved-memory. Новый материал проходит candidate → authorized approval.


## ADR-0014 — Кира:Сбор сначала работает через GitHub

**Статус:** принято

Первая Android-реализация использует private GitHub как универсальный transport/storage. Будущие VPS, SSH, Mesh и ServerSync подключаются через общий SyncProvider Contract.

## ADR-0015 — Приватная синхронизация всегда шифруется до GitHub

**Статус:** принято

GitHub не является доверенным plaintext-хранилищем персональных данных.

Приватные sync objects публикуются как encrypted envelopes с целостностью, provenance и подписью источника.

## ADR-0016 — Identity пользователя отделена от авторизации Алека

**Статус:** принято

identity_id/device_id/identity_secret отвечают за переносимость пользовательского профиля. Привилегии Алека являются отдельным authorization state и не восстанавливаются из имени, памяти или identity_id.

## ADR-0017 — Кира может хранить собственные реляционные интерпретации о пользователях

**Статус:** принято

Такие сведения относятся к пользовательской памяти, имеют provenance/confidence/privacy scope и не становятся GENOME.

Разрешены уровни Private, Shared-by-consent, Shared-derived и Public.

## ADR-0018 — Android и desktop используют общий семантический Persistence Contract

**Статус:** принято

Физические storage backend различаются по ОС. Android использует Room/SQLite, desktop Alpha сохраняет JSON/JSONL совместимость.

Кроссплатформенная идентичность достигается едиными stores, record semantics, versioning и migration rules.

## ADR-0019 — Runtime восстанавливается через checkpoints

**Статус:** принято

Процесс может быть уничтожен системой. Continuity реализуется через service/runtime + persistence + recovery.

Неопределённый внешний model-call получает состояние UNKNOWN и не повторяется молча.

## ADR-0020 — Каждый запуск получает временный runtime instance

**Статус:** принято

Каждая уникальная загрузка KiraCoreAI получает runtime_instance_id с ограниченным сроком жизни и provenance app/core/genome revision.

Регистрация не является пользовательской памятью.
