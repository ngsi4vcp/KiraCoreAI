# Модель контекста, состояния и памяти

Главная инженерная задача Кира:Ядра — контролировать, какая часть долговременной структуры становится оперативным контекстом модели.

## Канонические уровни

| Уровень | Назначение | Изменяемость |
|---|---|---|
| Геном | конституция | только контролируемая ревизия |
| Состояние | текущее рабочее состояние | высокая |
| Память | долговременная информация | управляемая |
| История | причинная линия | преимущественно добавляемая |
| Разговор | фактическая переписка | высокая, потенциально большой объём |
| Контекст | оперативный срез | временный |
| Среда выполнения | исполнение | зависит от реализации |
| Host | внешняя вычислительная среда | внешняя |

Разговор не является памятью. Память не является разговором. Контекст не является новым нормативным слоем.

## ContextCompiler

Компилятор получает:

- активную ревизию генома;
- состояние сессии;
- утверждённую память;
- причинную историю;
- хвост текущего разговора;
- текущую задачу;
- ограничения среды;
- выбранную модель.

Полная история разговоров не должна автоматически попадать в context.

## Память

Новая запись создаётся как candidate.

Только отдельное авторизованное действие переводит её в approved.

Модель не имеет прямого права записывать approved-memory.

После первого Alpha можно добавить структурированный extractor кандидатов памяти. Он должен создавать только candidate и прикладывать provenance, а не самостоятельно активировать запись.

## ПУЛЬС

PulseStamp формируется runtime и добавляется к соответствующему ходу разговора и агрегированному состоянию.

ПУЛЬС не является ключом хранения. Он используется как детерминированная метка корреляции.


## Семантическая проекция конституции

Операционный контекст не должен передавать модели полный текст защищённых секций GENOME.

Вместо этого ContextCompiler создаёт:
- семантическую проекцию публичных принципов;
- роль текущей сессии;
- capabilities;
- предгенерационную проверку;
- privacy/disclosure constraints.

Модель может выражать ценности и собственную позицию своими словами. Дословное цитирование GENOME не является целью и не считается источником авторитета.

## Защищённый authority plane

Пароль, verifier, protected payload и криптографические ключи не входят в ModelRequest.

Runtime является единственным авторитетным слоем, решающим вопрос о privileged capability.

## Фильтрация памяти по identity

Перед включением утверждённой памяти в ModelRequest ContextCompiler проверяет:

- статус approved;
- owner_identity_id;
- privacy_scope;
- текущий identity_id сессии.

Private-память другого identity не попадает в контекст модели.
