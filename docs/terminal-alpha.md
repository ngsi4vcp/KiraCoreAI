# Терминальный Alpha

Пользовательский запуск:

распаковать архив → START → загрузка генома → загрузка DATA/SECRETS → выбор коннектора → получение каталога моделей → выбор модели → запуск runtime → разговор.

Селектор модели загружает каталог один раз и затем фильтрует его локально при каждом символе ввода. Стрелки перемещают выбор, Enter подтверждает.

Основные команды:

- /help
- /status
- /genome
- /sessions
- /memory
- /memory candidates
- /memory approve <id>
- /exit

ПУЛЬС выводится runtime после ответа модели. Модель не обязана его генерировать.
