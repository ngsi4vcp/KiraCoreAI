# Kira Core Capsule

The Capsule is a portable representation of a specific Kira Core release for transfer into another context or runtime.

The Capsule is not the Core and is not authoritative over the Core.

Planned artifacts:

- `KIRA_CORE_CAPSULE.md`
- `KIRA_CORE_CAPSULE.json`

A released Capsule should identify:

- Core version;
- schema version;
- source commit or tag;
- provenance;
- compatibility information;
- the minimal state/context required for the intended bootstrap.
