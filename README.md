# KiraCoreAI

KiraCoreAI — переносимое Кира:Ядро с единым семантическим Core и отдельными платформенными реализациями.

## Архитектура

- `main` — общий Core и архитектурная база;
- `platform/android` — Android;
- `platform/windows-11` — Windows 11;
- `platform/linux` — Linux;
- `archive/history` — архив истории.

Начинать работу с `G22.txt`, затем читать `AGENTS.md` и `DOCUMENTATION.md`.

## Core

Общий Python Core, схемы, контракты и Core tests живут в `main`.
Платформа получает принятый срез Core из `main`, материализует его в своей ветке и тестирует связку Core+Platform отдельно.

## Геном

Активный runtime-источник: `GENOME/genome.txt`.
`G22.txt` — конституционный/разработческий документ по правилам проекта.
Текущая ревизия генома: 22.

## Документация

Главная карта: `DOCUMENTATION.md`.
Цель и план: `PROJECT-PLAN.md`.
Целевая архитектура: `PROJECT-ARCHITECTURE.md`.
Целевое поведение: `PROJECT-BEHAVIOR.md`.
Проверки: `PROJECT-CHECKLIST.md`.
Текущее состояние Core: `MAIN-STATUS.md`.

Временный `паспорт.мд` — контрольный паспорт текущей реорганизации. Он не является постоянным нормативным источником и будет переведён в историю после завершения миграционного цикла.

Не используйте архив как источник текущего состояния.

## Текущий фактический статус

- новая веточная архитектура создана;
- Core-only `main` сформирован;
- платформенные ветки сформированы и связаны с текущим `main`;
- старые ветки пока сохраняются до финального аудита;
- A2.2 остаётся реализованным срезом без финальной приёмки.
