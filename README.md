# KiraCoreAI — Кира:Ядро

Основной проект цифровой сущности **Кира:Ядро (Kira Core)**.

## Проект сейчас

Архитектура находится на стадии формализации. Текущая работа начинается с:

1. границ Core / State / Capsule / Runtime;
2. терминологии;
3. архитектурных решений;
4. последующей формализации Identity и остальных слоёв Core.
