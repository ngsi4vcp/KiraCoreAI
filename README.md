# KiraCoreAI — archive/history

Архив исторических веток и материалов проекта.

**Статус:** только справочная и восстановительная ветка. Разработка запрещена.

Актуальная архитектура находится в `main`; платформенные реализации — в `platform/windows-11`, `platform/linux` и `platform/android`.

История сохраняется намеренно. Не использовать содержимое архива как описание текущего состояния без сверки с актуальными ветками.

Основной реестр исторических веток: [LEGACY-BRANCH-REGISTRY.md](LEGACY-BRANCH-REGISTRY.md).
